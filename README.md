# Sistema de Autogestión Estudiantil

Proyecto desarrollado en Java utilizando Programación Orientada a Objetos (POO).

El sistema permite gestionar materias, asistencias, calificaciones y reportes académicos mediante un menú interactivo en consola.

* GitHub Desktop

## Conceptos aplicados

* Clases y objetos
* Herencia
* Interfaces
* Polimorfismo
* Encapsulamiento
* Métodos recursivos
* Validaciones y manejo de datos

---

## Funcionalidades principales

### Gestión de materias

* Inscripción a materias
* Baja de materias
* Validación de duplicados

### Gestión de asistencias

* Registro de asistencia
* Cálculo de porcentaje de asistencia
* Determinación de condición académica

### Gestión de calificaciones

* Registro de notas
* Validación de notas
* Cálculo de promedio
* Verificación de aprobación

### Reportes académicos

* Promedio general
* Estado académico
* Materias críticas
* Porcentaje de asistencia

---

## Extras implementados

* Validaciones de ingreso de datos
* Reintento de carga de notas inválidas
* Métodos `default` en interfaces
* Búsqueda recursiva
* Sistema de ranking académico
* Mejoras de experiencia de usuario en consola

---

## Ejecución del proyecto

1. Abrir el proyecto en NetBeans
2. Ejecutar:

```
AutogestionEstudiantil.java
```

3. Utilizar el menú interactivo en consola

---

## Organización del desarrollo

El proyecto fue desarrollado utilizando ramas para separar funcionalidades y mantener un trabajo colaborativo organizado.

Se trabajó principalmente con:

* `develop`
* `main`
* ramas `feature/*`
